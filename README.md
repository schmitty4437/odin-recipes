# odin-recipes

The Project

This little project allows me to practice my HTML knowledge up to this point
following the HTML Foundations course in The Odin Project. It is a basic 
recipe website with a home page and 3 recipes pages that are linked on the 
home page. This will only be done in HTMl without any CSS at the moment.


Demonstrated Skills

Completing this project I was able to demonstrate the following:

 Create an HTML boiler plate for my pages using semantic structure
 Use Headings elements  (h1, h2, h3)
 Use paragraph elements <p> 
 Use unorder lists <ul>
 Use order lists <ol>
 Use link element <a> to link each page with relative links
 Use image element <img> to displace images from the images folder
